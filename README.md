## 🚀 Despliegue Rápido en GitHub Pages

Este proyecto está 100% listo para publicarse en **GitHub Pages** sin necesidad de compilar o instalar dependencias:

1. Sube este repositorio a tu cuenta de GitHub (`git push origin main`).
2. Entra a tu repositorio en GitHub y ve a la pestaña **Settings** (Configuración).
3. En la barra lateral izquierda, haz clic en **Pages** (dentro de la sección *Code and automation*).
4. En la sección **Build and deployment**:
   - **Source**: Selecciona `Deploy from a branch`.
   - **Branch**: Selecciona `main` (o `master`) y carpeta `/(root)`.
5. Haz clic en **Save** (Guardar).
6. ¡Listo! En 1-2 minutos tu aplicación estará publicada en:
   ```text
   https://<tu-usuario-de-github>.github.io/<nombre-del-repositorio>/
   ```

## 🏝️ Estructura del Aprendizaje (3 Islas y 30 Módulos)

El archipiélago está dividido en 3 grandes islas de conocimiento:

### 1. ⚓ Isla HTML — La Estructura Sagrada (10 Módulos)
- **Módulo 1:** Estructura Básica y Doctype (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- **Módulo 2:** Encabezados y Párrafos (`<h1>`-`<h6>`, `<p>`)
- **Módulo 3:** Enlaces e Hipervínculos (`<a>`, `href`, `target="_blank"`)
- **Módulo 4:** Imágenes y Accesibilidad (`<img>`, `src`, `alt`)
- **Módulo 5:** Listas Ordenadas y Desordenadas (`<ul>`, `<ol>`, `<li>`)
- **Módulo 6:** Elementos Semánticos Modernos (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Módulo 7:** Formularios y Entradas (`<form>`, `<input>`, `<label>`, `placeholder`)
- **Módulo 8:** Tipos de Input y Opciones (`text`, `email`, `password`, `radio`, `checkbox`)
- **Módulo 9:** Tablas y Datos Tabulares (`<table>`, `<tr>`, `<th>`, `<td>`)
- **Módulo 10:** Metadatos y el `<head>` (`<meta charset>`, `<title>`, `<link>`)
- 💎 **Examen Final de HTML:** Cuestionario multidinámica para conquistar la isla.

### 2. 🎨 Isla CSS — Los Colores del Corsario (10 Módulos)
- **Módulo 1:** Sintaxis de CSS y Reglas (selectores, propiedades, valores)
- **Módulo 2:** Colores y Fondos (hexadecimal, RGB, RGBA, `color`, `background-color`)
- **Módulo 3:** El Modelo de Caja (`margin`, `border`, `padding`, `content`, `box-sizing`)
- **Módulo 4:** Bordes y Esquinas Redondeadas (`border`, `border-radius`, estilos)
- **Módulo 5:** Tipografía y Fuentes (`font-family`, `font-size`, `font-weight: bold`, `line-height`)
- **Módulo 6:** Unidades de Medida Web (`px`, `rem`, `em`, `%`, `vh`, `vw`)
- **Módulo 7:** Posicionamiento en CSS (`static`, `relative`, `absolute`, `fixed`, `sticky`)
- **Módulo 8:** Flexbox: Alineación de Tripulación (`display: flex`, `justify-content`, `align-items`, `gap`)
- **Módulo 9:** CSS Grid: La Cuadrícula del Tesoro (`display: grid`, `grid-template-columns`, `1fr`)
- **Módulo 10:** Diseño Responsivo y Media Queries (`@media (max-width)`, mobile-first)
- 💎 **Examen Final de CSS:** Cuestionario multidinámica para conquistar la isla.

### 3. ⚡ Isla Java scrp — La Magia de a Bordo (10 Módulos)
- **Módulo 1:** Introducción a JavaScript y la Consola (`<script>`, `console.log`)
- **Módulo 2:** Variables y Constantes (`let`, `const`, y por qué evitar `var`)
- **Módulo 3:** Tipos de Datos Primitivos (`string`, `number`, `boolean`, `null`, `undefined`)
- **Módulo 4:** Operadores y Comparaciones (`+`, `-`, `*`, `/`, `===`, `&&`, `||`, `!`)
- **Módulo 5:** Estructuras de Control (`if`, `else if`, `else`, condicionales)
- **Módulo 6:** Funciones: Órdenes del Capitán (`function`, parámetros, `return`, arrow functions)
- **Módulo 7:** Arreglos (Arrays) y Listas (`[]`, `push()`, `pop()`, `length`, indexación)
- **Módulo 8:** Objetos y Propiedades (`{ clave: valor }`, notación de punto)
- **Módulo 9:** El DOM: Interactuando con la Página (`getElementById`, `querySelector`, `textContent`)
- **Módulo 10:** Eventos e Interactividad (`addEventListener`, eventos de click)
- 💎 **Examen Final de JavaScript:** Cuestionario multidinámica para conquistar la isla.

## ✨ Características y Dinámicas

- 📜 **Lectura sobre Pergamino Antiguo:** Cada lección se presenta sobre una hoja de pergamino clásico con diseño limpio y fragmentos de código resaltados en cuadros de código.
- 🎯 **3 Preguntas de Verdadero / Falso por Módulo:**
  - Si el usuario se equivoca: La opción elegida se tiñe de **color rojo** con animación de alerta y la opción correcta se ilumina en **color verde**, mostrando una explicación pedagógica clara.
  - Si el usuario acierta: Se resalta en **color verde** con felicitación.
- 🦜 **Animación del Loro Pirata:** Al completar y finalizar cada lección, aparece un loro pirata animado batiendo las alas y celebrando con su bocadillo de diálogo.
- 🌊 **Animación de Olas en el Mar:** Al superar el examen final de cada isla, se despliega una animación de oleaje marino continuo con un navío navegando en la marea del triunfo.
- 👑 **Exámenes Finales con 3 Dinámicas:**
  1. *Verdadero o Falso*.
  2. *Opción Múltiple*.
  3. *Completar la Oración* (selección interactiva de fichas de palabras).
- 🌓 **Modo Claro / Modo Oscuro:**
  - **Modo Mar (Claro):** Pergamino cálido `#EEC67C`.
  - **Modo Noche (Oscuro):** Mar nocturno `#151922` con acento azul cian brillante `#07CEF5`.
- 🔊 **Efectos de Sonido Náuticos Sintetizados:** Generados en tiempo real mediante la **Web Audio API** (sin archivos externos pesados) con botón para silenciar.
- 💾 **Persistencia Automática:** Progreso guardado en `localStorage`.

## 🌐 Optimizaciones Técnicas

- **SEO Completo:** Metadatos primarios, Open Graph para redes sociales, Twitter Cards y datos estructurados Schema.org (`JSON-LD`).
- **GEO Tags:** Metadatos geográficos para motores de búsqueda (`geo.region`, `geo.placename`, `geo.position`, `ICBM`).
- **Favicon:** Brújula marina y rosa de los vientos en SVG nativo escalable (`favicon.svg`).
- **Accesibilidad (WCAG 2.1 AA):** Enlace de salto rápido (`skip-link`), navegación por teclado, contraste verificado y etiquetas semánticas con soporte ARIA.
- **Rendimiento:** Cero dependencias externas pesadas, carga instantánea y diseño responsivo móvil/escritorio.
